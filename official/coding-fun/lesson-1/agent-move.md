# Проведи Агента на золотую плиту

## Шаг 1
1. В синем блоке ``||player:при команде чата||`` стоит слово **go**. Не меняй его.
2. Перетащи внутрь синего блока ``||agent:агент: переместиться||``.
3. Посчитай клетки до золотой плиты и поставь это число.
4. Нажми зелёную кнопку с треугольником.
5. Вернись в игру, нажми **T**, напиши **go** и нажми **Enter**.

Плита за поворотом? Поставь перед «переместиться» блок ``||agent:агент: повернуться||`` и выбери сторону.

#### ~ tutorialhint
Агент встал не туда? Не собирай программу заново. Поменяй только число или сторону поворота.

player.onChat("go", function () {
})
