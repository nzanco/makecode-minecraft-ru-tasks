# По следам черепах

## Шаг 1
1. В синем блоке ``||player:при команде чата||`` стоит слово **go**. Не меняй его.
2. Посмотри, куда смотрит Агент и куда идут следы.
3. Собери внутри синего блока путь из блоков ``||agent:агент: переместиться||`` и ``||agent:агент: повернуться||``.
4. Скажи вслух, где Агент остановится и куда будет смотреть.
5. Нажми зелёную кнопку с треугольником.
6. Вернись в игру, нажми **T**, напиши **go** и нажми **Enter**.

Следы поворачивают на цветных плитках. Проходи их по кускам: Агент начинает с того места, где остановился, и смотрит туда же.

#### ~ tutorialhint
Агент встал не туда? Не собирай программу заново. Поменяй только число или сторону поворота.

player.onChat("go", function () {
})
