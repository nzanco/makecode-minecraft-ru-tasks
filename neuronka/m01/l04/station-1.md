# Маршрут к цели

## Станция 1 — Маршрут
1. Агент стоит на старте. Впереди дорожка из камня: она идёт вперёд и поворачивает направо. За поворотом — кирпич, а за ним золотая плита.
2. Программа **go** уже почти готова. Скажи вслух, где Агент остановится, если запустить её так. Нажми зелёную кнопку с треугольником, вернись в игру, нажми **T**, напиши **go** и нажми **Enter**.
3. Агент упёрся в кирпич. Добавь в программу ``||agent:агент: уничтожить||`` вперёд — в то место, где кирпич уже прямо перед Агентом.
4. Нажми кнопку у старта: Агент вернётся на место. Скажи, где он теперь остановится, и запусти **go** снова.

#### ~ tutorialhint
«Уничтожить» нужен сразу после поворота: тогда кирпич прямо перед Агентом.

```template
player.onChat("go", function () {
    agent.move(FORWARD, 3)
    agent.turn(RIGHT_TURN)
    agent.move(FORWARD, 3)
})
```

```ghost
player.onChat("go", function () {
    agent.destroy(FORWARD)
})
```
