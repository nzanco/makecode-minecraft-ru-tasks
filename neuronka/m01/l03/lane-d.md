# Агент ставит и ломает блоки

## Большая стена
1. Перед Агентом стена из досок: пять клеток в ширину и две в высоту. В ней **две дыры** и **три красных блока**.
2. В нижнем ряду слева направо: доска, дыра, красный блок, доска, доска. В верхнем: красный блок, доска, доска, дыра, красный блок.
3. Заполни обе дыры досками, а каждый красный блок замени доской. Агент должен стоять на клетку перед стеной; для верхнего ряда подними его на один блок.
4. Собери программу **go** из перемещений, поворотов, блоков ``||agent:агент: уничтожить||`` и ``||agent:агент: разместить||``. Перед запуском назови пять клеток, которые изменятся.

#### ~ tutorialhint
Красный блок сначала уничтожь, затем поставь доску в ту же клетку. Пустую клетку только заполни. Для верхнего ряда используй перемещение вверх.

```template
agent.setItem(PLANKS_OAK, 64, 1)
player.onChat("go", function () {
})
```

```ghost
player.onChat("go", function () {
    agent.move(FORWARD, 3)
    agent.turn(LEFT_TURN)
    agent.move(UP, 1)
    agent.destroy(FORWARD)
    agent.place(FORWARD)
})
```
