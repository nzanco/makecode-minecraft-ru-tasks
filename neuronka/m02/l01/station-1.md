# Повтор и сколько раз

## Станция 1 — Мост
1. Впереди канал с водой. Агент стоит на берегу и смотрит на канал. Блок ``||loops:при начале||`` даёт Агенту доски — не трогай его.
2. В программе **go** есть блок ``||loops:повторить||``. Внутри него два блока: Агент шагает вперёд и ставит доску под собой — направление **низ**. Число в повторе — сколько раз это сделать.
3. Скажи вслух, сколько досок ляжет и где остановится Агент. Нажми зелёную кнопку с треугольником, вернись в игру, нажми **T**, напиши **go** и нажми **Enter**.
4. Мост не дошёл до другого берега. Поменяй **только число** в повторе, чтобы доски легли через весь канал. Нажми кнопку у старта и запусти **go** снова.

#### ~ tutorialhint
Сосчитай клетки воды от берега до золотого блока. Один раз — одна доска.

```template
agent.setItem(PLANKS_OAK, 64, 1)
player.onChat("go", function () {
    for (let index = 0; index < 2; index++) {
        agent.move(FORWARD, 1)
        agent.place(DOWN)
    }
})
```
