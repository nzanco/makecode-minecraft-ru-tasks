# Внутри и снаружи

## Станция 1 — Полоса
1. Справа от Агента лежит полоса из шести камней. Агент смотрит вперёд, а не на полосу.
2. В программе **go** есть повтор: Агент ломает камень и шагает. Чтобы ломать камни полосы, Агенту нужно сначала один раз повернуться вправо.
3. Возьми блок ``||agent:агент: повернуться||`` и поставь его так, чтобы Агент повернулся **один раз** — до повтора. Поставь в повтор число, чтобы полоса исчезла вся.
4. Скажи вслух, какой блок выполнится один раз, а какие — каждый раз. Нажми зелёную кнопку с треугольником, вернись в игру, нажми **T**, напиши **go** и нажми **Enter**.

#### ~ tutorialhint
Поворот нужен один раз — он стоит над повтором. Сколько камней, столько раз.

```template
player.onChat("go", function () {
    for (let index = 0; index < 1; index++) {
        agent.destroy(FORWARD)
        agent.move(FORWARD, 1)
    }
})
```
