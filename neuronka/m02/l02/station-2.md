# Внутри и снаружи

## Станция 2 — Вокруг пруда
1. Перед Агентом трава, справа — пруд. Где пройдёт Агент, мир оставит тропинку.
2. Программа **go**: повтор 4 раза — «вперёд на 3», а после повтора — поворот вправо. Скажи вслух, где окажется Агент. Запусти **go** и проверь.
3. Агент должен обойти пруд и вернуться на старт. Перенеси **один блок** — поворот — внутрь повтора, под «вперёд на 3». Больше ничего не меняй.
4. Нажми кнопку у старта. Скажи, сколько раз Агент повернётся и где он остановится, и запусти **go**.

#### ~ tutorialhint
Поворот после повтора выполнится один раз. А повернуть нужно у каждого угла пруда.

```template
player.onChat("go", function () {
    for (let index = 0; index < 4; index++) {
        agent.move(FORWARD, 3)
    }
    agent.turn(RIGHT_TURN)
})
```
